# OSCAR typography sources

Source Sans3 and Source Serif4, Adobe Originals, SIL Open Font License1.1. Licenses are retained alongside the files. No renamed font or restriction on native accessibility fallback.

- Sans variable upright: https://raw.githubusercontent.com/google/fonts/main/ofl/sourcesans3/SourceSans3%5Bwght%5D.ttf
- Serif variable Roman: https://raw.githubusercontent.com/adobe-fonts/source-serif/release/VAR/SourceSerif4Variable-Roman.ttf
- License sources: adobe-fonts/source-sans and adobe-fonts/source-serif release/LICENSE.md.

Retrieved2026-10-12. Canonical copies here; identical platform copies in Desktop public/fonts and Android res/font. No runtime network fetch. Serif is reserved for sparse Desktop headings; Android declares but does not use its bundled Serif family. Sans carries body/controls on both platforms and all current Android headings. Segoe UI/Georgia and Android font fallback cover loading/missing glyphs. Variable weight rendering and physical readability still require owner quality review.
