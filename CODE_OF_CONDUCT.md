# Code of Conduct

OSCAR welcomes technical discussion, critique and contributions that improve the project.

## Expected behavior

- Be precise and constructive when reviewing ideas or code.
- Critique the work, not the person.
- Keep technical disagreements evidence-based.
- Respect privacy, especially around voice, memory, camera, account and device data.
- Do not publish secrets, private logs or exploit details that could harm users.
- Give credit for substantial ideas, code and research.

## Unacceptable behavior

- Harassment, threats or targeted abuse.
- Discriminatory or demeaning conduct.
- Deliberate disclosure of private information or credentials.
- Knowingly unsafe changes that bypass documented security/safety boundaries.
- Misrepresenting unimplemented features or test results as working.

## Enforcement

Project maintainers may edit, remove or reject content and contributions that violate these expectations. Serious security concerns should be reported through the process in `SECURITY.md` rather than discussed publicly.
