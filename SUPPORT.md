# Support

OSCAR is currently under active pre-alpha development.

## Where to start

- Product definition: `README.md` and `docs/PRODUCT.md`
- Current architecture: `docs/ARCHITECTURE.md`
- Planned work/status: `docs/ROADMAP.md`
- Feature inventory: `docs/FEATURES.md`
- Security questions: `SECURITY.md` and `docs/SECURITY.md`
- Agent/contributor workflow: `AGENTS.md` and `CONTRIBUTING.md`

## Issues

Use GitHub issues for reproducible bugs, scoped feature proposals and slice-specific engineering tasks.

Before filing an issue, check whether the capability is already planned in `docs/ROADMAP.md` or `docs/FEATURES.md`.

For security vulnerabilities, do not use a normal public issue; follow `SECURITY.md`.

## Current maturity

The repository is at **Slice 00 complete / Slice 01 next**. Features documented as planned should not be interpreted as already implemented.
