# Devices, Preferences and shared Workspace rhythm — 2026-10-13

Owner feedback authorizes Devices redesign, the remaining Preferences sections,
and consistent spacing/motion across every Workspace page.

Devices groups only the Core-advertised capabilities under their executor. Each
keyboard-accessible disclosure exposes operations, required scopes and risk.
Preparing an action opens the existing Act form with the capability selected;
it never queues or signs an action. Stale catalogs remain labeled as last observed.
No device online/health telemetry or complete Grid inventory is invented.

Preferences now gives explicit voice activation, unavailable awareness contracts,
Companion presence and private-draft clearing distinct, readable treatment.
Diagonal arrows are removed from the Workspace and Companion open control.

The shared shell uses a balanced 24px header inset, one 860px content measure,
32px content gutters (24px at narrow widths), stable scrollbar space, consistent
page headings and 24/32px control/section spacing. The header is a window toolbar;
its edge spacing is intentionally independent of the centered content column.

Motion connects actions to feedback: the navigation backplate moves to the
selected route, pages settle over 220ms, capability detail reveals over 180ms,
and controls/chevrons acknowledge interaction. Theme and shortcut motion remain.
There are no ambient graphic loops. Reduced motion removes spatial transitions
and smooth scrolling; state and keyboard focus remain visible.
