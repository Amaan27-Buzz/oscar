## Architecture and dependency order

One existing Harness composes Controller, Runtime, Executive, Grid, Model Router,
canonical SQLite Store/Event Archive, World Model and Policy. Native clients and
outbound Workers use authenticated enrolled sessions; they do not own a second
Core, conversation archive or scheduler. Derived memory remains rebuildable.

`D1 persistent Core → D2 authenticated Grid → accounts/capability projection →
signed native authority → existing native effects and Executive → independent
verification → native projection → integrated acceptance`.

Perception, retention and action grants remain independent. Signed standing
authority binds exact capability contracts, executor and owner sessions, account
generations, policy fingerprint, expiry and revocation epoch. Full activation
explicitly reviews enabled Ask rules; it cannot override native OS permissions,
provider consent or deterministic hardware safety. Uncertain effects retain a
durable pre-effect claim and require inspection rather than automatic replay.

  Core still checks actual expiry immediately before effects.

  under the authority-store lock through canonical mutation. Consumed reviews stay
  consumed when authority is withdrawn between review consumption and mutation.
- Native interactive-request error handling now clears Sentry notices, matching
  refresh failure behavior; actual revoked-session notice withdrawal passed.
- Mixed Desktop source encodings were corrected; typecheck/build/tests passed.
- UI heartbeat and executor liveness are independent; a crashed Worker cannot
  retain advertised control capabilities because its UI remains open.
- Full automation plans are included in signed edit/resume reviews. Learned
  procedure storage/evaluation requires independent retention consent.
- Briefing source visibility checks TTL, account generation and perception epoch;
  Desktop expiry advances from Core observation with monotonic elapsed time.
- Android cancellation generations prevent progression into a later HTTP phase
  or acceptance of a late response after cancellation, including during signing.
- Android snapshot refresh reads current presentation state after suspended
  history persistence, preserving a review dismissed or draft edited meanwhile.
- The installed Windows Python 3.14.2 repeatedly raised `MemoryError` at the
  recurring occurrence's `math.floor` call only after combined Executive tests;
